裂隙牌局 v0.4.4 Windows 便携版

启动方法：
1. 请先完整解压压缩包。
2. 双击 CardGame.exe。
3. 等待默认浏览器自动打开游戏。

不需要安装 Node.js，也不需要运行 npm 命令。

本地端口：
- 游戏页面：http://localhost:5173
- 本地游戏后端：http://localhost:3001

关闭“裂隙牌局启动器”窗口，会同时关闭本次启动的本地服务。

人机对战可完全在本机运行。
好友对战若要跨城市联机，仍需要连接已经部署的公网服务器；本便携版默认运行本地服务器。

如果提示端口被占用，请先关闭正在运行的旧版 CardGame 或占用 3001/5173 端口的程序。
